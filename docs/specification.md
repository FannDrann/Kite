# Спецификация языка Kite

## 1. Введение

Kite — учебный язык программирования со статической строгой типизацией в императивном процедурном стиле. Программа на Kite хранится в одном файле с расширением `.kite` и выполняется интерпретатором.

### 1.1. Ключевые особенности

- Программа состоит из объявлений структур и функций. Выполнение начинается с функции `main` без параметров и возвращаемого значения.
- Типы данных: целые числа `int`, вещественные числа `float`, логический тип `bool`, строки `string`, массивы и структуры.
- Типизация статическая и строгая: тип каждого выражения известен до запуска программы, неявных преобразований типов нет.
- Переменные объявляются явно — ключевым словом `var` с указанием типа.
- Управляющие конструкции: блок, ветвление `if`/`else`, цикл `while`.
- Ввод и вывод выполняются встроенными функциями.

### 1.2. Связь с другими языками

- Фигурные скобки для блоков, точка с запятой после инструкций, операторы `&&`, `||`, `!` — как в C, C# и Java.
- Тип записывается после имени через двоеточие (`count: int`) — как в Pascal, Kotlin и TypeScript.
- Функции объявляются ключевым словом `func` — как в Go и Swift.
- Тип массива `int[]` и создание массива через `new` — как в Java и C#.
- Структуры содержат только поля — как записи в Pascal и структуры в C.

### 1.3. Пример программы

```
// Находит максимальный элемент массива
func max(values: int[]): int {
    var result: int = values[0];
    var i: int = 1;
    while (i < len(values)) {
        if (values[i] > result) {
            result = values[i];
        }
        i = i + 1;
    }
    return result;
}

func main() {
    var values: int[] = new int[3];
    values[0] = 7;
    values[1] = 42;
    values[2] = 15;
    print(max(values));
}
```

## 2. Лексика

### 2.1. Общие правила

Исходный текст — файл в кодировке UTF-8. Символы вне ASCII допускаются только в строковых литералах и комментариях.

Лексический анализатор читает текст слева направо и разбивает его на лексемы следующих видов:

- идентификаторы;
- ключевые слова;
- литералы: целые, вещественные, строковые;
- операторы;
- разделители.

Пробельные символы и комментарии не являются лексемами: они разделяют лексемы и в остальном игнорируются.

На каждом шаге выбирается самая длинная последовательность символов, образующая лексему (принцип максимального захвата). Например, `if (x <= 10.5) { y = "ok"; }` разбивается на лексемы `if`, `(`, `x`, `<=`, `10.5`, `)`, `{`, `y`, `=`, `"ok"`, `;`, `}`.

Синтаксис лексем описан в нотации EBNF: `|` — выбор, `{ }` — повторение ноль или более раз, `"a" … "z"` — диапазон символов, символы в одинарных или двойных кавычках записываются буквально.

### 2.2. Пробельные символы

Пробельные символы: пробел (U+0020), горизонтальная табуляция (U+0009), возврат каретки (U+000D) и перевод строки (U+000A). Конец строки обозначается LF или парой CR LF.

Пробельный символ или комментарий нужен между лексемами только там, где без него они сольются в одну: `var x` — две лексемы, `varx` — один идентификатор, а `x=1` — три лексемы.

### 2.3. Комментарии

- Однострочный комментарий начинается с `//` и продолжается до конца строки.
- Многострочный комментарий начинается с `/*` и заканчивается ближайшим `*/`. Такие комментарии не вкладываются: в `/* a /* b */ c */` комментарий заканчивается после `b`, а `c */` разбирается как код.

Внутри комментария последовательности `//`, `/*` не имеют особого смысла. Внутри строкового литерала комментарий не начинается: `"// text"` — обычная строка.

### 2.4. Идентификаторы

```ebnf
identifier = letter { letter | digit } ;
letter     = "a" … "z" | "A" … "Z" | "_" ;
digit      = "0" … "9" ;
```

Идентификатор начинается с латинской буквы или `_` и продолжается латинскими буквами, цифрами и `_`. Длина не ограничена. Регистр букв различается: `count` и `Count` — разные идентификаторы.

Идентификатор не может совпадать с ключевым словом.

Примеры: `x`, `_tmp`, `maxValue`, `point2`.

### 2.5. Ключевые слова

Ключевые слова записываются строчными буквами. Регистр различается: `If` — идентификатор, а не ключевое слово.

| Ключевое слово  | Назначение                         |
|-----------------|------------------------------------|
| `func`          | объявление функции                 |
| `struct`        | объявление структуры               |
| `var`           | объявление переменной              |
| `int`           | целочисленный тип                  |
| `float`         | вещественный тип                   |
| `bool`          | логический тип                     |
| `string`        | строковый тип                      |
| `if`, `else`    | ветвление                          |
| `while`         | цикл с предусловием                |
| `break`         | досрочный выход из цикла           |
| `continue`      | переход к следующей итерации цикла |
| `return`        | возврат из функции                 |
| `new`           | создание массива                   |
| `true`, `false` | логические литералы типа `bool`    |

### 2.6. Литералы

#### 2.6.1. Целые литералы

```ebnf
int_literal = digit { digit } ;
```

Целый литерал — последовательность десятичных цифр, ведущие нули допускаются: `0`, `42`, `007`. Литерал имеет тип `int` — 64-битное целое со знаком, поэтому его значение не должно превышать 9 223 372 036 854 775 807 (2⁶³ − 1).

Знак не входит в литерал: `-5` — это оператор `-` и литерал `5`.

#### 2.6.2. Вещественные литералы

```ebnf
float_literal = digit { digit } "." digit { digit } ;
```

Целая и дробная части обязательны: `3.14`, `0.5`, `10.0`. Экспоненциальная запись не поддерживается.

Если за точкой не следует цифра, точка не входит в литерал: `5.` — это литерал `5` и разделитель `.`, а `.5` — разделитель `.` и литерал `5`.

Литерал имеет тип `float` — 64-битное число с плавающей точкой по стандарту IEEE 754. Значение округляется до ближайшего представимого числа.

#### 2.6.3. Строковые литералы

```ebnf
string_literal  = '"' { string_char | escape_sequence } '"' ;
escape_sequence = "\" ( '"' | "\" | "n" | "t" ) ;
```

Здесь `string_char` — любой символ, кроме `"`, `\`, CR и LF.

Строковый литерал заключается в двойные кавычки и располагается в одной строке исходного текста. Специальные символы записываются управляющими последовательностями:

| Последовательность | Символ                   |
|--------------------|--------------------------|
| `\"`               | двойная кавычка          |
| `\\`               | обратная косая черта     |
| `\n`               | перевод строки (LF)      |
| `\t`               | горизонтальная табуляция |

Литерал имеет тип `string`. Пустая строка `""` допускается.

Пример: `"Он сказал: \"Привет!\"\n"`.

#### 2.6.4. Логические литералы

Логические литералы `true` и `false` — ключевые слова типа `bool`.

### 2.7. Операторы

| Оператор             | Назначение                                          |
|----------------------|-----------------------------------------------------|
| `+`                  | сложение чисел, конкатенация строк                  |
| `-`                  | вычитание, унарный минус                            |
| `*`                  | умножение                                           |
| `/`                  | деление                                             |
| `%`                  | остаток от деления                                  |
| `==`, `!=`           | равно, не равно                                     |
| `<`, `<=`, `>`, `>=` | меньше, меньше или равно, больше, больше или равно  |
| `&&`                 | логическое И                                        |
| `\|\|`               | логическое ИЛИ                                      |
| `!`                  | логическое НЕ                                       |
| `=`                  | присваивание                                        |

Одиночные символы `&` и `|` лексемами не являются.

### 2.8. Разделители

| Разделитель | Назначение                                                              |
|-------------|-------------------------------------------------------------------------|
| `(`, `)`    | группировка в выражениях, параметры и аргументы функций, условия `if` и `while` |
| `{`, `}`    | границы блока и тела структуры                                          |
| `[`, `]`    | тип массива, индексация, размер массива в `new`                         |
| `,`         | разделение параметров и аргументов                                      |
| `;`         | завершение инструкции и объявления поля структуры                       |
| `:`         | отделение имени от типа                                                 |
| `.`         | доступ к полю структуры                                                 |

### 2.9. Лексические ошибки

Лексический анализатор сообщает об ошибке и указывает её позицию — номер строки и столбца, нумерация с 1. Ошибкой считается:

1. символ вне литералов и комментариев, не входящий ни в одну лексему, например `@`, `#`, `&` или буква кириллицы;
2. строковый литерал без закрывающей кавычки — символ CR, LF или конец файла раньше `"`;
3. неизвестная управляющая последовательность, например `\q`;
4. многострочный комментарий без закрывающего `*/`;
5. целый литерал больше 2⁶³ − 1;
6. буква или `_` сразу после целого или вещественного литерала, например `12abc`, `2point`, `1.5f`.
